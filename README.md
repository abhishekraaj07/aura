# Voice Assistant (Offline & Online Android Assistant)

An intelligent offline & online personal assistant application for Android built with Jetpack Compose, Material 3, Room, Text-to-Speech (TTS), and SpeechRecognizer.

## 📱 Download APK

You can download the compiled Android application APK directly:
- **Direct APK Location**: [`/apk/voice-assistant-debug.apk`](apk/voice-assistant-debug.apk)
- **Built File**: `app/build/outputs/apk/debug/app-debug.apk`

---

## ✨ Key Features
- **Offline & Online Voice Commands**:
  - Alarms, Timers, Reminders, and Calendar Events.
  - Calling & Speed Dialing (English & Hindi/Hinglish).
  - Time & Date queries.
  - Multi-turn conversation slot filling & confirmations.
- **Speed Dial & Phone Calls**:
  - Direct call execution (`ACTION_CALL`) or dialer fallback (`ACTION_DIAL`).
  - Speed dial favorites & device phonebook sync (`READ_CONTACTS`).
  - Interactive numeric dial pad.
- **Modern Jetpack Compose UI**:
  - Clean Material 3 design with dark mode and neon accents.
  - Adaptive layouts (Window Size Classes & Navigation Rail on wide screens).
  - Full local persistence with Room database.
